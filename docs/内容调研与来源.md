# 内容调研与来源说明

## 现状（诚实评估）

当前 `content/routes.ts` 是**结构化手写骨架**（季节、长短、慢住/快看、适老提示、预算量级），**尚未**系统对照小红书、知乎、马蜂窝等做逐条核验。配图多为 Unsplash，不是现场实拍。

对父母够用的「能走通的第一版」已有；要达到「靠谱攻略书」级别，需要下一阶段**人工调研 + 标注来源**。

## 推荐工作流（本项目）

预搜集 → 摘要 → 改写进 `content/`，原始数据不进部署：

1. **定线**：慢住基地 + 快看点（已有结构）。
2. **搜证**：`npm run research:list`，按词在小红书/知乎检索；可选 `npx redbook search "..."`，导出到 `research/raw/`。
3. **摘要**：写入 `research/notes/<路线id>.md`（用 `templates/note.md`）。
4. **改写**：更新 `content/routes.ts`（适老短句）+ `sources` 链接。
5. **复核**：出行前再对官网开放时间与票务。

## 建议优先搜索词（示例）

- `慕田峪 老人 缆车 避坑`
- `承德避暑山庄 电瓶车 两日`
- `大理 长住 短租 适老`
- `敦煌 租车 自驾 老人`
- `林芝 高原反应 适应`

## 本仓库的落地位置

预搜集数据放在 **`research/`**（不部署进网页）：

- `research/queries.json` — 每条路线搜索词  
- `research/notes/` — 人工摘要（可提交）  
- `research/raw/` — 原始导出（gitignore，勿含 Cookie）  
- `npm run research:list` — 打印全部待搜词  

详见 [research/README.md](../research/README.md)。
