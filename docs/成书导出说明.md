# 成书导出（二期预留）

本期网站 `content/` 即书稿源。成书时不要另起一套文案，按同一路线数据排版即可。

## 建议目录结构

### A. 按地区分章（对应 8 大区）

1. 京畿华北  
2. 东北林海  
3. 华东水乡  
4. 中原华中  
5. 华南岭南  
6. 西南秘境  
7. 西北丝路  
8. 青藏高地  

每章：大区简介（`regions.ts`）→ 长旅行 → 短途 → 各站图文与地图纵览截图。

### B. 按春夏秋冬分章

用每条路线的 `seasons[]` 归类；同一路线可在多季出现，正文只印一次并互见。

## 导出索引

```bash
npm run export:book-index
```

生成 `docs/book-index.md`：按地区 / 季节列出全部路线标题与 id，供排版对照。

## 地图与图

- 旅行页 **RouteOverviewMap** 可截图作章节扉页。  
- 首版配图为公开图源；成书前换成父母实拍或已授权图。

## 本期不做

专业 Indesign/LaTeX 排版、印刷装订、ISBN。
