# 离线打开说明

给父母用的两种方式：**在线链接**（有网）和 **离线 zip**（信号差时）。

## 方式一：在线（推荐有网时）

1. 手机浏览器打开：https://lanking520.github.io/china-travel-atlas/  
   （若打不开，仓库为私有时需先开通 GitHub Pages，或改用下方离线包。）
2. **添加到主屏幕**（像 App）：
   - iPhone：Safari → 分享 →「添加到主屏幕」
   - 安卓：Chrome → 菜单 →「添加到主屏幕」/「安装应用」
3. 有网时先多点几条路线，浏览器会缓存页面文字；外链图片/地图仍可能要网。

## 方式二：离线 zip（GitHub Releases）

1. 打开仓库 Releases，下载最新 **`china-travel-atlas-offline.zip`**（标签 `offline-latest`）。
2. 解压到电脑或传到手机文件管理。
3. **不要**直接双击用 `file://` 乱点（部分路由会坏）。推荐：
   - **电脑**：解压后在该文件夹打开终端，执行  
     `npx --yes serve -l 4173`  
     再用浏览器打开 http://127.0.0.1:4173/china-travel-atlas/  
     （若本地预览无 basePath，也可试 http://127.0.0.1:4173/ ）
   - **手机**：把解压目录拷进手机，用「能打开本地网站」的文件 App / 简易 HTTP 服务；或先在家用电脑开热点局域网访问。
4. 离线时以**文字路线、预算、出行提醒**为准；Unsplash 配图与外链地图可能空白。

## 微信里打不开？

用系统浏览器打开链接（右上角「…」→ 在浏览器打开）。不做小程序。

## 本地开发预览

```bash
npm install
npm run preview
```

打开 http://127.0.0.1:3000/

## 自行打包离线 zip

```bash
npm run pack:offline
```

会生成 `china-travel-atlas-offline.zip`（含 `out/` 静态站）。
